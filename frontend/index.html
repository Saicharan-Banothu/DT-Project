Audio Recording-Bias Audit

Raw audio datasets often carry recording biases. Preprocessing all audio with a standardized Telephony Profile (16 kHz mono, 300–3400 Hz bandpass, -20 dBFS loudness norm) reduced baseline acoustic shortcutting from 72.44% to 59.56%, ensuring the classifier relies on genuine vocal tension and temporal rhythm.

Live Listen Mode

100% On-Device Data Path

Microphone audio streams into an AudioWorklet and Web Worker inside your browser. Whisper transcribes speech via WebAssembly. Zero audio or transcript leaves your device.

Upload Analysis Mode

Uploaded recordings are processed in a private, owner-only server temp directory. After extracting acoustic signals, the file is immediately deleted in a finally block. Never stored in a database.
